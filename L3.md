What L3 Is (Very Clear Definition)

L3 = long-term financial lifestyle pattern

It answers:

> “What kind of financial behavior dominates this user over time?”



Key properties:

Slow-changing

Stable over months

Composed only from L2 patterns


No semantics, no labels during detection.

Core L3 Method (One Method Only)

✅ Long-Horizon Distribution Aggregation + Clustering

Same philosophy as L1 and L2.


---

L3 Detection: Step-by-Step (Exact)


---

Step 1: Fixed Long-Term Window

Window Definition

Fixed rolling window: 8 weeks
(can be 12 weeks if product prefers)


Why 8 weeks?

Enough to smooth noise

Captures salary cycles, habits

Still responsive to change


We segment the L2 sequence as:

Window 1 → Weeks 1–8
Window 2 → Weeks 2–9
...


---

Step 2: Long-Term Representation

Each 8-week window is converted into a distribution over L2 patterns.

If there are M L2 patterns:

Lifestyle vector L = [q1, q2, …, qM]

Where:

qi = fraction of weeks assigned to L2 pattern Hi

Σ qi = 1


This is the core L3 representation.


---

Step 3: Add Stability Meta-Features (Generic)

Same for all users:

Entropy of L2 distribution (stable vs volatile)

Number of distinct L2 patterns

Dominance ratio (max qi)


Still no rules.


---

Step 4: Normalize & Compress

Normalize vector

Optional PCA (2–4 dims)



---

Step 5: Unsupervised Clustering = L3 Detection

Cluster long-term vectors using:

k-means or

hierarchical clustering


Output:

User (or window) → L3 Pattern ID

Each cluster is a financial lifestyle.
