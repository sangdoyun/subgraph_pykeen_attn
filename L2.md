Pattern Detection – Core Metrics (Detailed & Concrete)

Pattern Type	Metric	Data Used	How It Is Computed (Precisely)	What It Validates

Temporal	Period Alignment Score	Timestamped action events (binned to 15–30 min)	For a candidate period τ (24h, 7d):<br>• Build binary series T(t)<br>• Compute overlap = Σ T(t)·T(t−τ)<br>• Normalize by total active bins	Confirms true periodic repetition (not frequency)
	Phase Stability	Same as above	• For detected period, collect time-of-day bins per cycle<br>• Compute variance of peak bin across cycles	Ensures routine happens at same time, not random
	Cycle Persistence Ratio	Same as above	• (# cycles where pattern detected) / (total cycles observed)	Filters one-off or short-lived routines
Sequential	Conditional Lift	Trigger events A, action events B, timestamps	• P(B|A) = count(A→B)/count(A)<br>• P(B) = count(B)/total events<br>• Lift = P(B|A)/P(B)	Proves causality beyond coincidence
	Delay Consistency	Same as above	• For each A→B occurrence, record delay Δt<br>• Compute stddev(Δt)<br>• Require stddev < threshold	Ensures predictable intent progression
	Trigger Coverage	Same as above	• (# A events followed by B within window) / (# A events)	Confirms sequence is reliable, not rare
Contextual	Context Lift	Context C (categorical), action A	• P(A|C) = count(C∧A)/count(C)<br>• P(A) = count(A)/total events<br>• Lift = P(A|C)/P(A)	Shows action is context-dependent
	Context Support	Same as above	• count(C) over observation window<br>• Must exceed minimum support	Prevents sparse-context overfitting
	Context Robustness	Same as above	• Recompute lift after removing one context dimension<br>• Lift must remain high	Ensures pattern survives missing signals
Person (Lens)	Relationship Persistence	Call/message events per contact, timestamps	• Divide time into windows (e.g., weeks)<br>• For each window, mark interaction present (1/0)<br>• Persistence = (# windows with interaction)/(total windows)	Identifies stable relationships vs transient
	Person-Conditioned Lift	Same + trigger/context	• Compute lift metrics conditioned on contact<br>• Compare vs global lift	Shows behavior is specific to person
	Selectivity Ratio	Same	• (# interactions with top K contacts)/(total interactions)	Ensures pattern is relationship-specific
On-Device (All)	Incremental Cost	Event counters	• O(1) updates per event<br>• No historical recomputation	Confirms mobile feasibility
	Pattern Half-Life	Pattern confidence over time	• Exponential decay if not reinforced<br>• Track time until confidence halves	Handles behavior drift safely
