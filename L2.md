Short answer: there is no widely adopted design in literature that cleanly integrates smartphone user data with agentic memory yet. Most work either handles agent memory or external data retrieval, but not both together in a mobile setting. So showing both approaches in the PPT is actually a good strategy.

Below is the closest existing designs from literature.


---

1️⃣ MemGPT / Letta (Agentic Memory OS Model)

Idea: Treat memory like an operating system.

Architecture:

Working context (current prompt)

Recall storage (recent memory)

Archival storage (long-term memory)

External data accessed via tools


User/device data fits as external tool calls.

Procedure:

Query
 → LLM
 → decide tool
 → fetch external data
 → add to context
 → answer

Pros

Clear separation of memory vs external data

Scales well


Cons

No structured representation of user knowledge

Weak personalization modeling



---

2️⃣ Mem0 (Production Memory Layer)

Mem0 pipeline:

messages
 → entity extraction
 → summary generation
 → memory update

Memory becomes persistent across sessions.

User data integration:

Typically injected as documents via RAG.


Pros

Simple production pipeline

Good conversation memory


Cons

Weak reasoning structure

Depends on summaries



---

3️⃣ Graph Memory Systems (A-Mem / Zep)

Architecture:

interaction
 → entity extraction
 → relation extraction
 → knowledge graph

Memory becomes a structured graph.

User data integration:

Usually preprocessed into graph entities.


Example:

Contact list
 → entity nodes
 → relations

Pros

Good reasoning

Strong personalization modeling


Cons

Graph construction overhead

Maintenance complexity



---

4️⃣ Smartphone Assistants (Closest Real Systems)

Apple Siri / Google Assistant architecture (conceptually):

User query
 → intent classifier
 → tool/API retrieval
 → device data access
 → response

They rely on:

Contacts

Calendar

Location

Messages


But they do not build persistent agent memory graphs.

Pros

Always up-to-date data

Efficient


Cons

No long-term learning

No cross-session memory



---

This gap is exactly where your proposal sits.
