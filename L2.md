🔷 Slide 1 — Why Agentic Memory?

Problem:

LLMs are stateless and bounded by context window.

Limitations:

Forget past sessions

Cannot accumulate experience

No personalization persistence

Poor temporal consistency

No self-improvement loop


Agentic Memory = external structured memory enabling:

Cross-session continuity

Personalization

Long-horizon reasoning

Self-evolution



---

🔷 Slide 2 — Major Directions in Literature

1️⃣ Graph-based Memory (A-Mem, Mem0, Zep)

Store entities and relations

Build knowledge graph from conversations

Support structured retrieval

Enable multi-hop reasoning


Goal: Move from flat vector memory → structured relational memory


---

2️⃣ OS-inspired Memory (MemGPT / Letta)

Idea: Treat LLM like CPU. Use:

Working context

Archival storage

Paging

Recall functions


Goal: Manage limited context window via memory virtualization.


---

3️⃣ Forgetting-Based Memory (MemoryBank)

Uses:

Forgetting curves

Memory strength decay

Spacing effect


Goal: Prevent memory bloat. Model human-like forgetting.


---

4️⃣ Summary-Based Persistent Memory (Mem0)

Pipeline:

Summarize recent messages

Extract entities

Update memory

Resolve conflicts


Goal: Production-ready persistent stateful agents.


---

🔷 Slide 3 — What Problems Are They Solving?

Paper	Core Problem Addressed

A-Mem	Structured organization of memory
Mem0	Persistent session memory
MemoryBank	Forget outdated info
MemGPT	Context window limitation
Zep	Temporal & enterprise memory


Common theme: 👉 How to store and retrieve long-term memory effectively.

🔷 Slide 4 — Technical Patterns Emerging

Across literature, common blocks:

Entity extraction

Relation extraction

Graph storage

Vector similarity retrieval

Summary generation

Temporal tagging

Memory update mechanisms

Conflict resolution

Memory decay / pruning


So field converges on: Hybrid graph + vector + summarization.

🔷 Slide 5 — What Is Still Missing?

Even with all these systems:

1️⃣ No Unified Memory Architecture

Most focus on:

One technique (paging, forgetting, summarization) But not holistic memory lifecycle.



---

2️⃣ Weak Credit Assignment

Few systems:

Track which memory caused success/failure

Adjust memory importance dynamically



---

3️⃣ Poor Memory Budget Management (Edge Devices)

Most assume:

Server-side deployment

Large storage

High compute


Not optimized for:

On-device agents

Smartphone constraints

Battery-aware memory



---

4️⃣ Retrieval Strategy is Static

Usually:

Fixed hybrid retrieval Not:

Query-aware adaptive routing



---

5️⃣ No Clear Separation Between:

Working memory

Episodic memory

Semantic memory Architectures mix them implicitly.



---

🔷 Slide 6 — Challenges in Agentic Memory

A. Scalability

Memory grows unbounded.

B. Temporal Consistency

Facts change over time. Contradictions accumulate.

C. Noise Accumulation

Irrelevant experiences pollute memory.

D. Personalization vs General Knowledge

How to separate user-specific vs global knowledge?

E. Efficient Retrieval Under Constraints

Mobile device:

Limited RAM

Limited compute

Limited storage


F. Memory Attribution

Which memory contributed to answer?

🔷 Slide 7 — Gap for Smartphone Agent

Current literature:

Designed for server-based AI agents

Focus on research benchmarks

Heavy LLM dependence

No strict memory budget enforcement


But smartphone agents need:

On-device storage

Privacy-first design

Bounded memory

Lightweight reasoning

Proactive use cases
