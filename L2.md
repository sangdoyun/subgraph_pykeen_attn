2. Redefining the Levels (in This Use Case)

L1: Atomic Modes / States (Predefined)

These are observable, low-level device or context states, already available on phones (Samsung-like).

Examples:

Location state: Home, Office, In-Transit

Connectivity: WiFi_On, WiFi_Off

Motion: Driving_Mode

Time bucket: Late_Evening

App foreground: Music_App, Netflix

Audio: Headphones_On


Key properties of L1

Predefined (not learned)

Discrete

Timestamped

Can overlap in time

Repeat frequently


👉 L1 answers:
“What state/mode is active at this moment?”


---

L2: Composite Routines / Micro-Habits (Learned)

L2 patterns are recurrent combinations or sequences of L1 states, often with temporal structure.

Examples:

Driving_Mode → Music_App (within 2 minutes)

Home + WiFi_On + Late_Evening → Food_Delivery_App

Friday_Evening + Home → Netflix


👉 L2 answers:
“What does the user typically do in this situation?”

These are action-triggering routines, not static profiles.

5. Step-by-Step Method

Step 1: Unified Event Stream

Convert everything into a time-ordered event stream:

[t=18:10] Location=Home
[t=18:11] WiFi=On
[t=18:15] Time=Evening
[t=18:20] App=Food_Delivery
[t=18:22] App=Music

Each entry is an L1 event.


---

Step 2: Temporal Segmentation (Crucial)

Split the stream into context windows, e.g.:

Entering Home

Driving session

Evening window (6pm–10pm)

Weekend block


These windows are not learned, just defined heuristically.

This prevents nonsense patterns across unrelated times.


---

Step 3: Sequence Construction

Within each window, build ordered sequences of L1 events:

Example (multiple days):

Day 1: Home → WiFi_On → Evening → Food_App
Day 2: Home → WiFi_On → Evening → Food_App
Day 3: Home → WiFi_On → Evening → Netflix

Now we have many sequences.


---

Step 4: Frequent Sequential Pattern Mining

Apply a method like:

PrefixSpan

SPADE

GSP (with time gaps)


We mine patterns like:

<Home, WiFi_On, Evening> → Food_App
<Home, WiFi_On, Evening> → Netflix
<Driving_Mode> → Music_App

These are candidate L2 routines.


---

Step 5: Pattern Scoring (Important)

Each pattern is scored by:

Support (how often it occurs)

Confidence (P(action | context))

Temporal tightness (short gap = stronger)

Consistency across days


Only patterns above thresholds are promoted.
