Pattern Detection Framework – Data, KPIs, and Evaluation

Pattern Type	Data Required (Granularity)	Key KPIs	On-Device Evaluation & Validation

Temporal Pattern	• Timestamped events (sec-level)<br>• App open/close<br>• Communication metadata (call/message timestamps)<br>• Optional: coarse location state (home/office)<br><br>Time bucketing: 15–30 min<br>Observation window: 2–4 weeks	• Periodicity score (24h / 7d alignment)<br>• Phase stability (variance of time window)<br>• Pattern confidence (repetition count × alignment strength)<br>• Miss tolerance (survives skipped days)<br>• False routine rate	• Holdout recurrence test (future days/weeks)<br>• Silent prediction: action occurs in predicted time window<br>• Confidence decay if pattern not reinforced<br>• Automatic retirement on drift
Sequential Pattern	• Timestamped trigger events (calendar end, salary credit, missed call, system state)<br>• Action events (message sent, purchase, app usage)<br><br>Trigger window: 5–30 min (fast)<br>24–48 hrs (slow triggers)	• Lift / dependency score P(B|A)/P(B)<br>• Average & variance of delay<br>• Trigger coverage (% A followed by B)<br>• Precision (true causal sequences)<br>• Stability across sessions	• Counterfactual test using shuffled triggers<br>• Silent prediction: B occurs after A within window<br>• Sequence deactivation if lift drops<br>• Trigger-specific confidence tracking
Contextual Pattern	• Timestamped action events<br>• Context signals (coarse):<br>  – time bucket<br>  – location state<br>  – motion state<br>  – connectivity state<br><br>Context resolution: categorical	• Context lift P(A|C)/P(A)<br>• Context purity (specificity of C)<br>• Generalization score (works with missing signals)<br>• Overfitting rate (context simplification survives)<br>• Temporal consistency	• Context contrast validation (inside vs outside C)<br>• Progressive context reduction if sparse<br>• On-device consistency check across days<br>• Drift detection when context no longer predictive
Person-Conditioned (Lens)	(Uses same data as above, grouped by contact/entity)<br>• Call/message metadata<br>• Contact identity (hashed)<br>• Temporal & contextual attributes	• Per-entity stability<br>• Conditional lift (given person)<br>• Relationship persistence<br>• Selectivity (not all contacts)	• Same evaluations as temporal / sequential / contextual<br>• Entity-specific confidence decay<br>• Automatic removal if interaction stops
System Constraints (All)	• Event-level logging only<br>• No content inspection<br>• No raw GPS / sensor streams	• CPU usage<br>• Memory footprint<br>• Battery impact<br>• Latency to detection	• Incremental counters only<br>• Fixed memory budget per pattern<br>• On-device only, no cloud dependency
