Detects periodicity even with missing days

High variance → noise

2️⃣ SEQUENTIAL PATTERN DETECTION

(order of actions)


---

Module: Variable-Order Dependency Learner

Input

Sessionized event sequences


S = [e1, e2, …, en]


---

Core Computation

Step 1: Build Conditional Transition Tables

Instead of fixed Markov order:

P(e_k | e_{k−1})
P(e_k | e_{k−2}, e_{k−1})

Only keep longer history if it improves prediction.


---

Step 2: Predictive Gain Test

For candidate sequence A → B → C:

Gain = P(C | A,B) − P(C | B)

If Gain < ε → discard longer dependency.

This prevents overfitting and explosion.


---

Output

SequentialPattern = {
  sequence [A → B → C],
  confidence,
  avg_time_gap
}

Why Accurate & Feasible

✔ Learns only meaningful order
✔ Adapts sequence length per user
✔ Sparse tables (memory safe)
✔ No deep sequence models needed

Module: Context–Action Sensitivity Analyzer

Input

Context vector per session:

Action A



---

Core Computation

Step 1: Context-Conditioned Distributions

Maintain:

P(A | C)
P(A)   (global)

Incrementally updated.


---

Step 2: Mutual Information (Approximated)

Compute:

MI(A, C) ≈ P(A | C) · log(P(A | C) / P(A))

We only compute this for observed context–action pairs, not full cartesian product.


---

Step 3: Generalization

If context too sparse:

Back off dimensions (e.g., drop network_state)

Recompute MI
