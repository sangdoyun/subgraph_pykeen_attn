1️⃣ Temporal Patterns

(When something reliably happens)

What it captures

Stable time-based routines that repeat daily, weekly, monthly, or seasonally — even if some days are skipped.


---

Use Case 1: Morning Information Routine

Observed behavior

User opens News app between 7:30–8:15 AM on most weekdays


Temporal pattern

> “User has a morning information-check routine.”



Smartphone value

Preload news content

Delay non-urgent notifications

Show daily briefing automatically



---

Use Case 2: Friday Night Entertainment

Observed behavior

Long Netflix sessions every Friday evening

Not present on other days


Temporal pattern

> “Friday evening is a recurring entertainment window.”



Smartphone value

Suggest new shows at the right time

Optimize network usage

Trigger smart-home / DND mode



---

Use Case 3: End-of-Month Financial Activity

Observed behavior

Multiple payment and banking app opens in last 3 days of each month


Temporal pattern

> “Monthly financial maintenance routine.”



Smartphone value

Surface pending bills

Show budget summaries

Reduce irrelevant offers earlier in month



---

Use Case 4: Late-Night Scrolling

Observed behavior

Short social app usage after 11 PM

Irregular duration but consistent timing


Temporal pattern

> “Late-night lightweight content consumption.”



Smartphone value

Enable eye comfort mode

Suggest wind-down content

Reduce notification interruptions

2️⃣ Sequential Patterns

(What tends to happen after what)

What it captures

Intent progression — actions that reliably follow a trigger within a short time window.


---

Use Case 1: Meeting → Reply Manager

Observed behavior

After client meetings end, user messages manager within ~10 minutes


Sequential pattern

> “Meeting completion triggers managerial follow-up.”



Smartphone value

Suggest quick-reply drafts

Surface manager chat automatically

Reduce friction after meetings



---

Sequential pattern

Smartphone value

Suggest savings/investment options

Calibrate fraud detection thresholds

3️⃣ Contextual Patterns

(What happens in a specific situation)

What it captures

Actions that are significantly more likely in a particular context than overall.


---

Smartphone value

Notification suppression
